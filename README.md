# F6 SP Lesson 7 - DSE 2012 & 2013 Paper 1: True / False / Not Given

Helen's F.6 English SP lesson pack on the **True / False / Not Given** question type -
every question of this type that appears in the 2012 and 2013 HKDSE English Language Paper 1.

No vocabulary and no exam tips: the lesson is the exam questions only, each with the
complete exam paragraph(s) printed underneath for students to read.

## The eight questions (28 statements, 28 marks)

| Year | Paper | Q | Text / paragraphs | Marks | Answer | Correct % |
|------|-------|---|-------------------|-------|--------|-----------|
| 2012 | Part A  | Q8  | Text 1, paragraphs 8-9   | 4 | T / F / F / T | 78 / 39 / 82 / 72 |
| 2012 | Part B1 | Q34 | Text 2, paragraphs 13-21 | 4 | F / T / NG / T | 62 / 68 / 64 / 59 |
| 2012 | Part B2 | Q51 | Text 4, paragraphs 2-3   | 3 | NG / T / F | 82 / 79 / 84 |
| 2013 | Part A  | Q6  | Text 1, paragraphs 2-3   | 3 | NG / T / F | 72 / 61 / 67 |
| 2013 | Part A  | Q21 | Text 1, paragraph 11     | 3 | T / F / F | 64 / 68 / 40 |
| 2013 | Part B1 | Q32 | Text 2 (whole text)      | 4 | T / NG / F / T | 83 / 67 / 76 / 51 |
| 2013 | Part B1 | Q42 | Text 3, paragraphs 7-9   | 3 | T / F / T | 57 / 36 / 47 |
| 2013 | Part B2 | Q52 | Text 4, paragraphs 4-5   | 4 | F / T / NG / F | 84 / 88 / 87 / 68 |

* Statement (iv) of 2013 Part A Q6 was deleted by HKEAA: it is left out of the lesson and
  the question is scored out of 3.
* Percentages are the proportion of DSE candidates who got each statement right - they are a
  useful signal of which statements are genuinely hard (36% for 2013 B1 Q42 (ii)) and which
  are easy (88% for 2013 B2 Q52 (ii)).
* All answers, percentages and evidence wording are taken from the official HKEAA marking
  schemes for the 2012 and 2013 papers.
